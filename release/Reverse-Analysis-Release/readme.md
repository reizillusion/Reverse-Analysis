# 逆转数分

> Reverse Analysis  
> 一款以数学分析证明题为核心的校园推理辩论游戏。

## 项目概述

`逆转数分` 是一个纯前端单机项目，整体风格参考《逆转裁判》，但将“证词漏洞”替换为“数学证明中的逻辑漏洞、条件遗漏与定理误用”。玩家扮演主角 `王若臣`，在宿舍自习室、图书馆讨论间、研讨间、湖边石桌区、答疑间等校园场景中，与同学、学长学姐和助教围绕数学分析相关命题展开一轮轮质询。

项目目标不是简单地把题目做成选择题，而是把“定义、定理、反例、计算、逻辑箭头”组织成一套可游玩的推理流程。玩家需要：

- 阅读剧情与对话
- 识别 NPC 论证中的错误位置
- 从证据卡中选择正确定义、定理或反例
- 在关键节点进行指证、选择、推进或回击
- 在有限信誉值内完成整个案件的驳斥

当前版本已经实现完整可运行的主体流程，包括：

- 主菜单、案件目录、案件解锁、结局页
- 六个完整案件
- 对话打字机效果
- 证据卡展示与出示
- 多轮反驳与错误反馈
- 信誉值系统
- 本地进度保存
- 立绘、场景背景、UI 爆发图、音效与背景音乐接入
- 资源缺失时的程序回退机制

## 项目详细介绍

### 核心设计思路

项目的核心不是“背答案”，而是“拆论证”。每个案件都围绕一个高等数学或数学分析中的典型错误展开，例如：

- 把单向定理当双向定理
- 把局部条件误写成全局结论
- 把上确界偷换成最大值
- 在换元里漏掉 Jacobian
- 在保守场判别里忽略区域条件
- 在高阶微分方程里少写独立解

玩家看到的每一句“证词”，本质上都是一个可被检查的数学陈述。游戏把原本静态的证明阅读过程改写成了动态辩论：

- NPC 先给出一个看似合理、实则有漏洞的说法
- 玩家再从“定义 / 定理 / 反例 / 计算”中调度证据
- 系统根据预设的关卡结构判定当前反驳是否命中关键破绽

这使项目同时具备两种用途：

1. 作为一个可游玩的校园数学推理作品
2. 作为一个将证明题拆成步骤化、结构化过程的教学原型

### 案件一览

1. `第一案：尖点不是断点`
   - 主题：连续、可导与逆命题误用
   - 场景：宿舍楼公共自习室
2. `第二案：上确界不在场`
   - 主题：极值定理、闭区间条件、supremum 与 maximum 的区分
   - 场景：图书馆玻璃讨论间
3. `第三案：积分不会治疗一切`
   - 主题：微积分基本定理的条件扩写与阶跃函数反例
   - 场景：图书馆报告角
4. `第四案：雅可比失踪案`
   - 主题：二重积分换元、正逆 Jacobian、面积因子
   - 场景：数院研讨间
5. `第五案：洞口旁的零旋度`
   - 主题：曲线积分、保守场、单连通条件
   - 场景：校园湖边石桌区
6. `第六案：重根少写一维`
   - 主题：高阶微分方程、重根解结构、Wronskian 与解空间维数
   - 场景：本科生答疑研讨间

## 玩法与交互说明

### 基本流程

每个案件大致按照以下顺序推进：

1. 从目录页进入案件
2. 阅读案件引导与背景说明
3. 进入正式质询
4. 逐句推进剧情
5. 在反驳节点完成选择或出示证据
6. 成功则进入下一阶段，失败则扣除信誉值并收到反馈
7. 案件完成后进入结案总结
8. 六案全部完成后进入最终结局页

### 系统机制

- `证据系统`
  - 玩家持有定义、定理、反例、结论等证据卡
  - 不同反驳节点要求不同类型的证据或选项

- `信誉值系统`
  - 每案有独立信誉值
  - 错误选择会扣除信誉值
  - 信誉值归零则本案失败，需要重试

- `进度保存`
  - 已完成案件会保存在浏览器本地
  - 刷新页面后仍可继续

- `音效与视觉反馈`
  - 成功反驳会触发“异议！”爆发图与音效
  - 失败会触发“驳回”提示、震动与扣分反馈
  - 初始界面与六个案件会自动切换低音量循环背景音乐
  - 全部通关后会播放结束音效 `end.ogg`

### 快捷操作

- `空格`
  - 在游戏页面中推进下一句对话
- `Esc`
  - 关闭允许关闭的弹窗

## 启动方式

当前发布版面向普通 Windows 用户，已内置本地启动脚本。  
使用时无需额外安装 Python、Node.js、VS Code 或其他开发环境。

请勿直接双击 `index.html` 或以 `file://` 方式打开项目，否则 ES Module、背景图、音频等资源可能无法正常加载。

### 标准启动步骤

1. 如果收到的是 `Reverse-Analysis-Release.zip`，请先完整解压到本地普通文件夹，不要在压缩包预览中直接运行。
2. 打开发布目录 `Reverse-Analysis-Release`。
3. 双击 `Start-Reverse-Analysis.bat`。
4. 程序会自动启动本地服务，并在默认浏览器中打开游戏。
5. 游戏结束后，关闭启动脚本窗口即可停止本地服务。

### 启动文件说明

- `Start-Reverse-Analysis.bat`
  - 面向普通用户的默认启动入口
  - 会自动调用同目录下的 PowerShell 启动脚本

- `Start-Reverse-Analysis.ps1`
  - 实际执行本地静态服务的脚本
  - 通常无需手动运行，除非需要排查启动问题

### 使用注意事项

- 首次启动时，Windows 可能弹出 PowerShell 或浏览器权限提示，允许后即可继续。
- 若浏览器没有自动打开，请查看脚本窗口中显示的本地地址，通常形如 `http://127.0.0.1:87xx/`。
- 若浏览器首次不播放音频，通常是自动播放策略限制；点击页面后即可恢复。
- 若资源刚更新但页面效果未变化，先执行一次 `Ctrl + F5` 强制刷新缓存。
- 运行期间请保持发布目录结构完整，不要单独移动 `index.html`、`assets`、`music`、`src` 或 `styles`。

- `背景音乐`
  - 位于 `music/`

### 资源回退机制

即使资源文件缺失，项目也尽量保持可运行：

- 立绘缺失时，自动退回首字占位卡片
- 音频缺失或格式不兼容时，自动回退到 Web Audio 合成音
- 背景缺失时，仍保留基础氛围层与渐变遮罩，不至于白屏


## 技术实现说明

### 技术栈

- HTML5
- CSS3
- 原生 JavaScript（ES Module）
- Web Audio API
- 浏览器本地存储 `localStorage`

### 架构概览

- `src/main.js`
  - 创建游戏实例并完成启动

  - 管理屏幕切换

  - 集中维护六个案件的剧情、节点、分支、结案总结

- 逻辑和内容数据分离

- 便于直接继续扩案件、扩证据库、扩资源
